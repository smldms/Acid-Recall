# ACID RECALL 1.1 — Laptop compatibility test

27 November 2026. **Test build for feedback; the stable 1.0 download is unchanged.**

[Official website](https://acidrecall.com)

Download **ACID-RECALL-1.1.0-LAPTOP-TEST-Windows-x64.zip**, extract it, and double-click
**ACID-RECALL.exe**. Version 1.1 should open on the affected Windows 11 Intel laptop without
setting `WGPU_BACKEND` in PowerShell. Confirmation on that laptop is still needed.

- Windows initializes **DirectX 12 only** by default, before graphics adapter enumeration.
  This avoids the Vulkan startup path involved in the reported `igvk64.dll` crash.
- `--graphics dx12|vulkan|auto` is a documented launch option and overrides `WGPU_BACKEND`.
  Existing valid environment overrides remain supported. Automatic selection is opt-in on Windows.
- macOS/Linux graphics defaults, the rack, audio/MIDI behavior and .recall/.orb338 compatibility
  are unchanged. The application and Windows file properties identify this build as **1.1.0**.

Read **README-GRAPHICS.md** in the ZIP for launch options and diagnostics. Please test a normal
double-click launch without the old workaround, then playback and reopening an existing project.
The user report identifies a failing Vulkan path; it does not establish whether the original
root cause lies in the Intel driver, wgpu, or application configuration.
